# SafeBath Mobile

Android app skeleton for connecting to the SafeBath backend.

## Open in Android Studio

Open the `mobile/` directory as a project.

## Backend base URL

Update `app/src/main/java/com/safebath/mobile/network/ApiConfig.kt` before running:

- Android emulator: `http://10.0.2.2:8000/`
- Physical device: `http://<YOUR_PC_IP>:8000/`
